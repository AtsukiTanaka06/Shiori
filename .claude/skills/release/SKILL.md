# Release Skill

リリース前の包括的なチェックを実行します。

## チェックリスト

### コード品質
- [ ] `npm test` — テスト全通過
- [ ] `npx tsc --noEmit` — 型エラーなし
- [ ] `npx eslint .` — lint エラーなし

### ビルド
- [ ] `npx expo export` — エクスポート成功
- [ ] EAS Build でビルド成功
- [ ] iPhone での動作確認

### セキュリティ
- [ ] APIキーがソースコードにないこと
- [ ] `.env` が Git にコミットされていないこと
- [ ] Supabase RLS が有効であること
- [ ] `service_role` key がクライアントにないこと

### 環境変数
- [ ] `.env.example` と実際の `.env` が揃っていること
- [ ] EAS の環境変数が設定されていること

### DB
- [ ] migration が最新であること
- [ ] 本番 DB のスキーマが正しいこと

### アプリ情報
- [ ] `app.json` の `version` が更新されていること
- [ ] アプリ名・バンドル ID が正しいこと

### 動作確認
- [ ] 主要ユースケースが動作すること
- [ ] エラー状態が適切に表示されること
- [ ] ローディング状態が適切に表示されること

## リリース手順

1. 上記チェックリストを全確認
2. ユーザーに確認・承認を得る
3. EAS Build でビルド
4. TestFlight で確認
5. App Store 申請
