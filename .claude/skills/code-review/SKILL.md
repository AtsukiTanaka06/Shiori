# Code Review Skill

コードを厳格にレビューします。

## チェック項目

### バグ
- 論理エラー
- 境界値の処理
- null/undefined の扱い
- 非同期処理のエラー

### セキュリティ
- `.claude/rules/security.md` の違反
- 認証・認可の漏れ
- RLS の考慮
- 入力バリデーション

### 型安全性
- `any` の不適切な使用
- 型アサーションの乱用
- 型定義の不備

### パフォーマンス
- 不要な再レンダリング
- N+1 クエリ
- 重い処理のメインスレッド実行

### 可読性・保守性
- 変数・関数の命名
- 関数の長さ・複雑さ
- コメントの適切さ

### アーキテクチャ
- レイヤー違反（コンポーネントからDB直接アクセス等）
- 責務の分離
- 重複コード

### テスト
- テストカバレッジの不足
- テストの品質

## 判定

- 問題なし：「LGTM」と明示
- 問題あり：問題・重要度・改善案を具体的に記載
- ブロッカー：マージ前に必ず修正が必要な問題を「BLOCKER」として分類
