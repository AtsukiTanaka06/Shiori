# UI Review Skill

UIを包括的にレビューします。

## チェック項目

### レイアウト
- 画面サイズ（iPhone各種サイズ）への対応
- SafeArea への対応
- キーボード表示時のレイアウト崩れ
- スクロール可能な長いコンテンツの処理

### UX
- 操作のフィードバック（タップ時の視覚的反応）
- ローディング状態の表示
- エラー状態の表示
- 空状態（データなし）の表示
- 成功時のフィードバック

### アクセシビリティ
- `accessibilityLabel` の設定
- タップ領域の大きさ（最低 44x44pt）
- コントラスト比

### 一貫性
- デザインシステムとの整合性
- フォント・カラー・スペーシングの一貫性
- アイコンの一貫性

### iOS固有
- iOS のナビゲーションパターンへの準拠
- ジェスチャー操作
- Dynamic Type 対応

## 指摘形式

- 問題：〇〇
- 重要度：高/中/低
- 改善案：〇〇
