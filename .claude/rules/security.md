# Security Rules

## シークレット管理

- APIキーをソースコードにハードコードしない
- 秘密情報を Git にコミットしない（`.gitignore` を確認する）
- `.env.local` を使用し、`.env.example` のみ Git 管理する

## Supabase キーの扱い

- Supabase `anon` key はクライアントに使用可（公開前提）
- Supabase `service_role` key は絶対にクライアントに使用しない
- Supabase RLS を必ず有効化する

## 認証・認可

- 認証と認可を明確に分離する
- 認証済みでない場合はデータを表示しない
- アカウント削除時はユーザーデータを適切に削除する
- Apple Sign In のトークンを適切に管理する

## ユーザー入力

- ユーザー入力を信用しない（バリデーションを実施する）
- 書籍検索クエリ・感想・メモ・ISBN はバリデーションをかける

## ログ・デバッグ

- デバッグログに個人情報を含めない
- エラーメッセージに内部情報を含めない

## ストレージ

- AsyncStorage に機密情報を保存しない

## Expo 設定

- `app.json` の `extra` に secret を公開しない
- EAS の環境変数を適切に設定する
