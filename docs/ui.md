## 基本方針

- `src/constants/design.ts` のトークンを必ず使う（ハードコードしない）
- 背景は warm ivory `#FFFDF8`（pure white を避ける）
- プライマリボタンは sage `#899B8C`（黒を避ける）
- タッチターゲット最小 44×44pt
- `Input/Design.md` の Do/Don't に従う

## タブバー

本棚 ⇄ カレンダーの2タブ（`@expo/vector-icons` の Ionicons を使用）。

- 本棚: `book-outline`
- カレンダー: `calendar-outline`

選択中は `sage600`、非選択は `ink400`。背景は `ivory50`、上ボーダーは `line200`。

## カレンダー画面（日記）

`react-native-calendars` の月表示カレンダー + 選択日の読書中リスト。

```
[月表示カレンダー]

2026-09-20 に読書中の本
[表紙] タイトル
       メモあり / メモを書く
[表紙] タイトル
       メモあり / メモを書く
```

- カレンダーで選択した日を `sage500` でハイライト（デフォルトは今日）
- リストの本をタップ → 下からモーダル表示、複数行 TextInput でメモを編集・保存（1本×1日につき1件、上書き）
- 読書中の本が0件の場合は空状態メッセージを表示

## 本の詳細画面（日記セクション）

書籍情報の下に「日記」セクションを追加し、その本の日記メモを日付の新しい順にカード表示する。

```
[表紙]  タイトル
        著者名
        読了 / これから

日記
2026-09-20
  メモ本文...
2026-09-18
  メモ本文...
```

0件の場合は「まだ日記がありません。カレンダー画面から記入できます。」を表示。
