詳細は `Input/Design.md` を参照。デザイントークンは `src/constants/design.ts` に定義済み。

### スペーシング

8pt ベースグリッド。画面水平パディング: 16pt。

### 角丸

ボタン・入力: 12pt / カード: 16pt / モーダル: 24pt

---

## 基本方針

- `src/constants/design.ts` のトークンを必ず使う（ハードコードしない）
- 背景は warm ivory `#FFFDF8`（pure white を避ける）
- プライマリボタンは sage `#899B8C`（黒を避ける）
- タッチターゲット最小 44×44pt
- `Input/Design.md` の Do/Don't に従う
