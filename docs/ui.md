# UI Design

## 基本方針

- React Native 標準コンポーネントを基本とする
- iOS のデザインガイドラインに準拠
- シンプルで直感的な UI
- ダークモード対応（将来検討）

## 画面一覧

| 画面 | ファイル | 説明 |
|------|---------|------|
| 本棚 | `app/index.tsx` | メイン画面 |
| 本を追加 | `app/add/index.tsx` | 登録方法選択 |
| バーコードスキャン | `app/add/scan.tsx` | カメラ起動 |
| 本の検索 | `app/add/search.tsx` | 検索フォーム・結果 |
| 書籍情報・登録 | `app/add/register.tsx` | 確認・登録 |
| 本の詳細 | `app/books/[id].tsx` | 詳細表示 |
| 本の編集 | `app/books/[id]/edit.tsx` | 編集フォーム |
| ログイン | `app/login.tsx` | 認証 |
| 設定 | `app/settings.tsx` | アカウント管理 |
