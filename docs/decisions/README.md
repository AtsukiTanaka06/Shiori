# Architecture Decision Records (ADR)

重要な技術判断を ADR として記録します。

## 目的

- なぜその技術を採用したか
- 何を検討したか
- 何を捨てたか

を記録し、将来の開発者（または自分）が判断の背景を理解できるようにします。

## テンプレート
