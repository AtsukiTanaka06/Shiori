# Requirements

元ドキュメント：`Input/読書記録アプリ_要件定義書.md`

---

## 概要

本を読んだ記録を残し、自分の読書履歴を本棚として管理・振り返るための iPhone アプリ。

---

## 主要機能（MVP）

| 機能 | 概要 |
|------|------|
| バーコードスキャン登録 | Expo Camera でバーコードを読み取り、ISBN から書籍情報を取得して登録する |
| 書籍検索登録 | タイトル・著者・ISBN で書籍を検索して登録する |
| 本棚表示 | 登録した本を一覧表示する（リスト / カバーグリッド 切り替え可） |
| ステータスフィルター | すべて / これから / 読了 で絞り込む |
| 本の詳細表示 | 書籍情報と読書記録を表示する |
| 読書記録管理 | ステータス・読み始め・読み終わり・評価・感想・メモを登録・編集する |
| 本の削除 | 読書記録を削除する |
| アカウント認証 | Supabase Auth（Sign in with Apple 優先）でログイン・ログアウト・アカウント削除 |
| データ引き継ぎ | 同じアカウントで再ログインすると読書記録を復元できる |
| 日記 | カレンダー画面で日付を選び、その日読書中の本に日ごとのメモを記録する（1本×1日につき1件、上書き編集） |

## MVP 対象外

- 同一書籍の再読管理
- AI機能・ソーシャル機能・課金機能・読書統計

## 読書記録

| 項目 | 必須 | 備考 |
|------|------|------|
| ステータス | 必須 | to_read（これから）/ reading（読書中）/ finished（読了） |
| 読み始め | 任意 | 「読書中」を選択した場合は登録時に今日の日付を自動設定 |
| 読み終わり | 任意 | |
| 評価 | 任意 | 1〜5の5段階（なしも可） |
| 感想 | 任意 | |
| メモ | 任意 | 感想とは別項目 |
| 登録日時 | 自動 | |

### ステータスの制約

- 読み始め・読み終わりはどちらも任意入力
- 「読了」でも日付未入力を許容する

---

## 日記

- カレンダー画面（デフォルトで今日の日別ビュー）に、その日「読書中」の本の一覧を表示する
- 「読書中」の判定：`started_at` が設定済み かつ（`finished_at` が未設定、またはその日以降）。ステータスが `reading` かどうかは判定に使わない（`started_at`/`finished_at` の日付のみで判定する）
- 本をタップしてその日のメモを記入・保存できる（1本×1日につき1件、上書き編集）
- 本の詳細画面では、その本に紐づく日記メモを日付順（新しい順）に一覧表示する

---

## 本棚

- デフォルト表示：登録日時の新しい順
- 表示形式：リスト表示 / カバー表示（グリッド）を切り替え可
- フィルター：すべて / これから / 読書中 / 読了（デフォルト「すべて」）

## エラー・例外処理

### バーコード
- カメラ権限拒否
- 読み取り失敗
- ISBN 取得失敗
- API 通信エラー
- 書籍が見つからない場合は検索画面へ移行

### 書籍検索
- 書籍が見つからない
- API 通信エラー
- 表紙画像が存在しない
- 書籍情報の一部が存在しない

### 登録
- 二重登録時はユーザーに通知する
- 登録処理失敗
